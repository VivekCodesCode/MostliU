# MostliU Website

A responsive, multi-page HTML/CSS/JavaScript website for MostliU.

## Pages
- `index.html` — home page and company overview
- `services.html` — software development, automation, websites and IT consulting
- `products.html` — product overview
- `ejipg.html` — detailed EjiPG product concept page
- `industries.html` — healthcare, hospitality and retail
- `about.html` — company approach
- `contact.html` — enquiry page
- `styles.css` — shared responsive design
- `script.js` — shared mobile navigation, current year and demo contact-form behaviour

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel
Keep the project as a static site (Preset: Other; Root Directory: `./`). Leave Build Command, Output Directory and Install Command blank. Ensure `index.html` is in the repository root.

## Before publishing
- Replace `hello@mostliu.com` with your real business email if needed.
- The contact form is front-end only. It validates and displays a demo message; it does not send or store enquiries. Connect a backend or form service before launch.
- EjiPG is presented as a product concept / early exploration, not as a currently live service. Finalise features, verification, privacy, moderation, consent and legal processes before accepting real users or resident ratings.
- Sample property/resident visuals and labels are illustrative only; no real user ratings or resident data are shown.
- Add privacy policy, terms, business address and social links before launch.

This is plain HTML/CSS/JavaScript. No npm install or build step is required.
